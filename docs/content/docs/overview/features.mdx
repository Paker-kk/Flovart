Flovart 是面向 Coding Agent 的本地优先 AI 视频制作系统。创作界面由 Workflow 与 Table 两个职责清晰的工作区组成。

## 创作工作区

| 工作区 | 职责 | 当前状态 |
| --- | --- | --- |
| **Workflow** | 编排提示词、参考素材、生成模型、节点依赖、任务状态与结果；支持图片和视频生成链路。 | 已有可用基础，持续收敛交互与 Runtime 契约。 |
| **Table** | 组织 Agent 故事版和媒体预处理节点，把源媒体加工为可复用参考素材。 | 正式入口已接入；当前仍是占位界面，节点工作台待实现。 |

旧 Canvas / Art 工作区已经删除，不再作为第三套创作系统恢复。

## Workflow

- 使用图片、文本、视频、音频和配置节点组织生成链路。
- 通过 PromptBar 选择产品模型、生成模式、参数和参考素材。
- 支持节点连线、项目切换、本地媒体拖入、生成状态、停止与结果节点。
- 通过本地素材库复用角色、场景、道具和生成产物。
- 当前 CLI 注册表提供 Workflow 项目、节点、连线、视口、运行和停止命令。

## Table

Table 不是电子表格，也不是旧 Canvas 的改名。它计划提供两组渐进披露的节点能力：

- **Agent 故事版**：Brief、段落、场景、镜头和分镜卡片，支持 Agent Skill 生成、拆解与修订故事板。
- **媒体预处理**：图片或视频输入、人物抠图、深度图与深度视频、边缘/线稿/法线/姿态提取、风格化与故障滤镜，以及服装修改和全能参考前的素材准备。
- **产物交接**：处理结果保留来源关系，可保存到素材库并作为 Workflow 的参考输入。

Table 主体尚未完成；在对应节点、持久化与导出链路落地前，不应把上述计划能力描述为已可用。当前 CLI 也没有 Table 命令。

## Agent 与 CLI

- Coding Agent 负责理解 Brief、拆解任务、选择 Skill、监控执行并处理失败。
- Flovart CLI 是确定性执行器；命令和参数以 `command.list` 与 `command.schema` 为唯一事实源。
- 当前自动化能力以 Workflow 为主。Agent 不得伪造 Canvas、Element 或 Table 命令，也不得绕过 CLI 拼接私有 HTTP 请求。
- Provider 凭据由用户配置，CLI 和 Agent 输出不得读取或泄露 API Key。

## 本地优先边界

- 当前工作区项目、素材与生成记录主要保存在浏览器本地，不承诺云同步。
- 当前 API Key 保存在浏览器本地，并由前端直接请求用户配置的模型服务。
- Flovart 不内置模型服务；用户需要自行确认输入素材与生成内容的版权和合规性。
