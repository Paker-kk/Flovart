# 后端数据库结构

Flovart Hub（`backend/` 目录）使用 PostgreSQL，GORM AutoMigrate 自动建表。本文件随表结构变化同步更新。

## users — 共享生态用户

| 字段 | 类型 | 说明 |

| email | varchar(255) unique | 小写存储 |
| password | varchar(255) | bcrypt hash，不出现在 JSON |
| bio | varchar(500) | 个人简介 |
| avatar_url | varchar(500) | 头像 URL（R2 链接） |
| role | varchar(16) | `user` \| `admin` |
| created_at | timestamptz | |

- `users.username` 唯一索引
- `users.email` 唯一索引
- `prompt_packs.slug` 唯一索引

## department_members — 部门成员绑定（enterprise 服务）

部门级角色绑定（非 org 级）。同一用户可在多个部门。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | uuid PK | |
| dept_id | uuid FK → departments.id | |
| user_id | uuid FK → users.id | 复用 hub 共享 users 表 |
| is_lead | bool | 是否部门负责人 |
| roles | uuid[] | 绑定的角色 ID 列表 |
| created_at | timestamptz | |
| updated_at | timestamptz | |

唯一约束 `(dept_id, user_id)`：同一用户在同一部门只一条记录。

## roles — 组织角色（enterprise 服务）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | uuid PK | |
| org_id | uuid FK → organizations.id | |
| name | varchar(60) | 角色名 |
| is_builtin | bool | `Owner` / `Admin` 两个预置角色 |
| permissions | text[] | 权限点列表（14 个硬编码权限点子集） |
| sort | int | |
| created_at | timestamptz | |
| updated_at | timestamptz | |

建组织时自动 seed `Owner`（全权限）和 `Admin`（除 `org:manage` + `view:audit_log`）两个 builtin 角色。
权限通过 PostgreSQL `WITH RECURSIVE` CTE 求用户在（本部门 ∪ 祖先部门）上所有角色的 `permissions` 并集。

## 索引（enterprise 基础）

- `organizations.slug` 唯一
- `organizations.owner_id` 普通

## 权限点（14 个硬编码常量）

| 权限点 | 说明 | owner | admin |
| --- | --- | --- | --- |
| `org:manage` | 改名/删除组织 | ✅ | ❌ |
| `member:invite` | 邀请成员 | ✅ | ✅ |
| `member:manage` | 调整/移除成员、部门角色 | ✅ | ✅ |
| `dept:manage` | 部门 CRUD | ✅ | ✅ |
| `role:manage` | 角色增删改 | ✅ | ✅ |
| `credit:grant` | 提交充值申请 | ✅ | ✅ |
| `credit:adjust` | 人工调整余额 | ✅ | ✅ |
| `apikey:manage` | API Key 池增删改 | ✅ | ✅ |
| `pricing:manage` | 模型单价配置 | ✅ | ✅ |
| `quota:manage` | 成员月度额度配置 | ✅ | ✅ |
| `asset:approve` | 资源审批 | ✅ | ✅ |
| `asset:publish` | 资源发布 | ✅ | ✅ |
| `workflow:publish` | 发布工作流 | ✅ | ✅ |
| `view:audit_log` | 审计日志 | ✅ | ❌ |

owner 走 `Organization.OwnerID` 快通道拥有全部权限；admin 预置角色拥有除 `org:manage` 与 `view:audit_log` 外的全部权限。member 无管理权限，只读组织信息。

## credit_transactions — 积分变动流水（enterprise）

不可变。每笔变动一条记录。

| kind | varchar(16) index | `recharge` \| `consume` \| `refund` \| `adjust` \| `grant` |
| amount | int64 | 正数入账，负数扣减 |
| balance_after | int64 | 本次变动后余额，便于审计 |
| ref_request_id | uuid index nullable | 关联 RechargeRequest ID |
| ref_usage_id | uuid index nullable | 关联 UsageRecord ID |
| reason | varchar(200) nullable | 人工备注/失败原因 |
| created_at | timestamptz index | |
