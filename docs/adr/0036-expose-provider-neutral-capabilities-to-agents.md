# 向 Agent 暴露 Provider-neutral Capability 而不是 Provider Job

Flovart Skill、Coding Agent、CLI、MCP 与 WebUI 通过 `capability.submit` 或建立在其上的 Production Intent Command 请求图片、视频、语音、音乐、渲染和验证能力，只表达 Capability Requirement、输入 Artifact、质量约束、预算和目标，不直接提交 Provider endpoint 或持有 Provider Secret；Desktop Runtime 根据用户已确认的 Product Route Binding 解析并锁定 Route，再在内部创建 ProviderAttempt，通过私有 Provider Worker IPC 完成 submit、poll 与 cancel。这样社区 Production Skill 可以跨 Provider 复用，Provider 路由、参数差异、凭据和 Submission Unknown 处理集中在一个深 Runtime Module 内；代价是专家不能绕过 Runtime 直接控制任意 Provider payload，如需诊断只能使用受控 operator 命令和脱敏记录，不能扩大公共 UGC Skill 接口。
