# 发布真实作品与可选 Remix Bundle

App Home 的 Community Gallery 展示创作者明确发布的最终图片或视频，不使用长期假数据冒充社区，也不把 Workflow 图作为首页主体。Local Work 在用户执行发布前保持本地私有；发布边界必须明确选择媒体、公开元数据和许可，不得自动上传项目、历史或私有素材。

Published Work 可以选择附带 Remix Bundle，它由一个精确、不可变的 Community Production Skill 版本与一份 Reference Workflow Snapshot 组成。参考快照只保留节点、连线、提示词、产品模型、生成参数和明确公开的参考素材；Provider Secret、Route、费用、运行历史、Agent 会话、本地路径和私有素材必须移除。接收者使用自己的 Route Mapping 创建新项目，不能复用发布者的执行权限。
