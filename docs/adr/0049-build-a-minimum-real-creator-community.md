# 将 V1 UGC 首页建设为最小真实创作者社区

Flovart 的 App Home 不交付只含内置假数据的视觉首页，也不限制为管理员策展库。V1 Community Gallery 允许所有访客公开浏览 Published Work，已登录创作者可把最终图片或视频明确发布到线上，并可选择绑定由 Community Production Skill 精确版本和 Reference Workflow Snapshot 组成的 Remix Bundle；Local Work 在明确发布前保持本地私有。这个边界要求后续落实真实身份、作品存储、Skill 分发、审核与 Remix 来源关系，但首页始终以最终媒体而非 Workflow 图为展示主体。
