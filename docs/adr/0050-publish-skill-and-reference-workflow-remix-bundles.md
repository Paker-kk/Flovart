# 发布由 Skill 与参考 Workflow 组成的 Remix Bundle

Published Work 可选择绑定 Remix Bundle，复刻对象不是单独 Workflow，而是一个精确、不可变的 Community Production Skill 版本与一份 Reference Workflow Snapshot。复刻时 Skill 加入接收者的 Skill 库，并以参考 Workflow 创建新项目；参考快照只保留节点、连线、提示词、产品模型身份、生成参数和明确公开的参考素材，API Key、Provider Route、费用与运行历史、Agent 会话、本地存储路径和私有素材必须在发布边界移除，接收者用自己的模型映射重新解析执行线路。这样把可复用创作方法与可运行示例一起交付，同时避免社区内容成为秘密或本机数据的泄露通道。
