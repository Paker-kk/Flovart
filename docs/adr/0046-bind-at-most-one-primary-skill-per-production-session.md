# 每个 ProductionSession 至多绑定一个 Production Skill

Flovart V1 允许 ProductionSession 不绑定 Production Skill，此时 Flovart Agent 直接使用 ProductionSpec Core 进行通用制作，不创建虚构的通用 Skill；需要特定方法时，用户可以确认一个 Bound Production Skill（绑定的制作 Skill），并在 ProductionSpec Revision 中锁定精确 Skill 版本或 Skill Snapshot。Agent 可以根据 Brief 推荐 Skill 并说明风格、审片与步骤影响，但不得静默建立或切换绑定；切换必须作为显式重新规划产生新的 ProductionSpec Revision，使旧 Production Mandate 及其未完成审查失效，已完成产物可作为新修订的参考，已提交的 ProductionRun 则按原授权继续、暂停或取消而不被原地改写。第二个 Production Skill 不能同时改写同一作品的叙事弧、阶段、Extension 和 Skill Gate。这个“零或一个”边界牺牲任意多 Skill 混搭，换取低门槛默认体验、可验证 Schema、可复现规划、清晰撤销和准确 Skill Eval。本 ADR 不使用“主 Skill”一词，以免与操作 Skill（Operation Skill，见 ADR 0054）的俗称混淆。
