# 分离 Workflow 与 Table 工作区职责

Flovart 只保留两个正式创作工作区：Workflow 负责提示词、参考素材、模型配置、生成依赖、任务状态与结果节点的编排；Table 负责 Agent 故事版、源媒体组织和媒体预处理节点。两者共享 Provider、Asset、Artifact 与产品模型语义，但分别维护适合自身任务的界面状态和工具层级。

Table 的预处理产物包括深度图或深度视频、人物抠图、风格化或故障滤镜、边缘或法线等派生媒体，以及为服装修改和全能参考准备的素材。产物必须保留来源关系，可进入素材库并作为 Workflow 的参考输入。

Table 内部采用“统一图 + 焦点面板”：故事卡、媒体和处理节点共享同一项目图与来源关系，选中节点后才展开紧凑参数；只有抠图和逐帧视频等高复杂度任务进入焦点编辑。不得再拆成故事版与预处理两张内部画布，也不得把全部工具和参数常驻铺满界面。

已经删除的 Canvas / Art 工作区不得作为第三工作区恢复；`Artboard` 也不得用作 Table 的产品名称。Table 命令尚未进入 Canonical Command Registry 时，Agent、CLI 与 Skill 不得虚构 Table 自动化能力。
