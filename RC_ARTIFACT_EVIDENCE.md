# Release Candidate Artifact Verification

The release workflow now verifies staged installer contents after checksum and
SPDX generation. scripts/check-release-artifacts.mjs checks that every
installer filename contains the canonical release version, every installer is
covered exactly once by SHA256SUMS.txt, every recorded digest matches the
bytes on disk, and the supplied SBOM is parseable SPDX JSON.
The tag-only release path stages `latest.json` and `.sig` sidecars in each
matrix job, then the final publish job downloads the complete draft asset set
and checks that every updater entry points to a versioned staged artifact with
the matching signature text via `scripts/check-updater-artifacts.mjs`.
